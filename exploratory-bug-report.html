DEF-01 | TC-SF-07
EU VAT Formátum Regex Szintaxishiba (B2B Adómentesség Blokkolása)
Kritikus Funkcionális

Reprodukálás

  1. Nyissa meg a Storefront & Checkout fület.
  2. Adjon meg egy valós EU adószámot (pl. DE987654321).
  3. Kattintson a "Verify VAT" gombra.

Várt vs Tényleges Működés

Várt: Zöld visszajelzés és 0% B2B Reverse charge adómentesség alkalmazása.

Tényleges: A rendszer "Invalid EU VAT syntax" hibát jelez és felszámolja a 27%-os ÁFÁ-t.

Technikai Hibaok

A reguláris kifejezés elgépelése miatt numerikus számjegyek helyett a 'd' betűt keresi:

/^(HU|DE|AT|FR)d{8,9}$/.test(val) // HIBA: \d helyett d szerepel
DEF-02 | TC-INT-01
SQL Workbench SELECT és UPDATE Reguláris Kifejezés Parser Hiba
Kritikus Funkcionális

Reprodukálás

  1. Navigáljon az SQL Workbench fülre.
  2. Futtassa a szabványos "SELECT * FROM orders;" lekérdezést.

Várt vs Tényleges Működés

Várt: A rendelések táblázatos megjelenítése az SQL eredménykonténerben.

Tényleges: A konzol szintaktikai hibát dob, az adatok nem jelennek meg.

Technikai Hibaok

Szintaktikailag hibás regex kifejezések az SQL motorban (\s+ helyett s+):

/^SELECTs+/i.test(sql) // HIBA: szóközök helyett s betűt vár a SELECT után
DEF-03 | TC-INT-03
SQL Audit Napló Lekérdezés Blokkolódása
Magas Funkcionális

Reprodukálás

  1. Nyissa meg az SQL konzolt.
  2. Futtassa a "SELECT * FROM audit_logs ORDER BY id DESC;" lekérdezést.

Várt vs Tényleges Működés

Várt: Az audit események listájának renderelése.

Tényleges: A lekérdezés ismeretlen táblaként elutasításra kerül.

Technikai Hibaok

/FROMs+audit_logs/i.test(sql) // HIBA: \s+ helyett s+ szerepel

DEF-05 | TC-EXP-08
Nemzetközi Megrendelések ÁFA Kulcsának Hibás Rögzítése (Fix 27%)
Magas Funkcionális

Reprodukálás

  1. Storefront felületen válasszon német (DE - 19%) vagy amerikai (US - 0%) célországot.
  2. Adja le a megrendelést.
  3. Vizsgálja meg az elmentett rendelési objektumot.

DEF-07 | TC-EXP-02
Kupon Minimális Kosárérték Kijátszása Termékváltással (SAVE100 Bypass)
Magas Funkcionális

Reprodukálás

  1. Válassza ki a $490-es terméket.
  2. Aktiválja a SAVE100 kupont (Minimum spend: $300).
  3. Váltson át az olcsóbb, $250-es termékre.

Várt vs Tényleges Működés

Várt: A kupon automatikus érvénytelenítése vagy törlése.

Tényleges: A kupon aktív marad, $250-ből $100 levonásra kerül ($150-ért megvásárolható a termék).

Technikai Hibaok

A termékválasztó eseménykezelő nem hívja meg a kupon-érvényesség revalidációs logikát.
